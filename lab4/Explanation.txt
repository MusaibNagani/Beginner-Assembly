lab4a.asm - Description
This assembly program generates a Fibonacci sequence using a loop. The program starts by initializing the registers EAX, EBX, EDX, and ECX, where ECX is used as the loop counter set to 6. The program enters a loop labeled L1, where it calculates the next number in the Fibonacci sequence by adding EBX and EDX, then updating the values of EBX and EDX accordingly. The DumpRegs procedure is called within each iteration of the loop to display the current state of the registers, allowing the user to observe the Fibonacci sequence generation in real-time. The loop continues until ECX decrements to zero, at which point the program exits.

lab4b.asm - Description
This assembly program demonstrates overflow and underflow conditions in an 8-bit register (AL). The program first moves the maximum value that an 8-bit register can hold (0xFF, or 255) into AL and then adds 1 to it, causing an overflow, which sets the Carry Flag (CF). Next, the program moves the minimum value (0x00) into AL and subtracts 1, causing an underflow, which again sets the Carry Flag. Finally, the program performs a simple subtraction of 0 from 1, which does not affect the Carry Flag. After each operation, DumpRegs is called to display the register values and the status of the Carry Flag.
